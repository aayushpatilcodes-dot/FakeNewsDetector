# Screenshots

This folder is for screenshots of the running Streamlit app, to include in the lab report/presentation.

No browser/screenshot tool was available in the environment this project was built in, so screenshots were not auto-captured. To add them before your presentation:

```bash
streamlit run app/app.py
```

Then paste a REAL example and a FAKE example into the text box, click **Analyze**, and screenshot both results into this folder (e.g. `app_real_example.png`, `app_fake_example.png`).
